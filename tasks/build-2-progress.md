## Lessons / surprises (live)
- **macOS TCC blocks launchd-spawned Python from reading user data.** The Engine ran fine for Build 1 because it only read from the SQLite catalog DB. Build 2's `/file` opens source files directly — and Voice Memos data is TCC-protected. Terminal-launched Python has FDA via Terminal's grant; launchd-launched Python doesn't. Symptom: 200 with correct Content-Length, but zero body bytes streamed. Fix: grant Full Disk Access to `venv/bin/python` in System Settings. Will recur for Photos library, Mail, Messages, etc. Logged in `docs/lessons.md`.
- **Python import paths follow the `-m` launch target.** The plist runs `python -m automation.api.server`, so server.py's package is `automation.api`. The default awk-inserted `from file_endpoint import file_router` failed (sys.path root is `/Users/jontollefson`, not the api dir). Fixed by switching to relative: `from .file_endpoint import file_router`. Worth checking the launch command before assuming top-level module imports.
- **`pkill -f uvicorn` may kill the parent shell** if uvicorn was started as a child of an open Terminal. Use `launchctl kickstart -k` for launchd-managed agents instead.
- **Astro middleware needs a dev-server restart when first added.** HMR picks up changes to existing middleware files, but adding `src/middleware.ts` for the first time doesn't register without `preview_stop` + `preview_start`. Worth a note in `docs/lessons.md` if it recurs.
- **Astro 5+ ships built-in CSRF check on POST.** Form submissions without an Origin header matching the host get 403'd. Browsers send Origin automatically so the login form works; curl tests need `-H "Origin: http://localhost:4321"`. Real-browser flow is unaffected.
- **Tailscale-to-Vercel routing is unsolved.** The Portal will work in local dev (M3 reaches M1 over Tailscale), but Vercel's serverless functions don't sit on Jon's Tailnet by default. Logged in `docs/lessons.md` with options: Tailscale Funnel (public URL with auth) or Vercel's Tailscale connector beta. Doesn't block Build 2 development; does block prod deploy.
